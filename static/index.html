使用说明

关于统计和接入

Token 怎么计算
网站不返回精确用量，本机使用 cl100k_base 分词估算，包含消息结构开销。
响应时间包含什么
从代理收到请求到响应完成的总时间，只统计成功请求；首字时间是第一段文字到达的耗时。
时区
按 Asia/Shanghai 切分自然日，数据保存在本机 SQLite。
Responses 接续
使用 previous_response_id 接续已保存的响应；store=false 时不会保存到本机。
